# Phần A - Tổ chức thư mục bằng GUI
## A1. Bật hiển thị đuôi file và file ẩn trong File Explorer/Finder. Bước này hỗ trợ làm bài và không tính điểm.
- Ấn vào thư mục cần bật đuôi ẩn chọn view trên thanh Taskbar chọn Show và chọn file name extensions.
## A2. Đổi tên thư mục gốc thành trung-tam-tieng-anh.
- Chọn thư mục cần đổi tên
- Click chuột phải vào thư mục
- Chọn rename và đổi thành trung-tam-tieng-anh
## A3. Tạo 5 thư mục trong thư mục gốc: docs, media, data, logs, archive
- Dùng phím tắt Ctrl + Shift + n để tạo nhanh thư mục
- Mỗi lần tạo 1 thư mục thì đổi tên tương ứng là docs, media, data, logs, archive.
## A4. Đổi tên đúng 5 file Logo Trung Tam.PNG, Anh Lop Hoc.JPG, Lich Hoc.txt, Hoc Vien Khoa 3.xlsx, Access.log theo dạng snake_case
- Logo Trung Tam.PNG -> logo_trung_tam.png
- Anh Lop Hoc.JPG -> anh_lop_hoc.jpg
- Lich Hoc.txt -> lich_hoc.txt
- Hoc Vien Khoa 3.xlsx -> hoc_vien_khoa_3.xlsx
- Access.log -> access_log
## A5. Dùng GUI chuyển file Excel vào data, file log vào logs. Giữ logo, ảnh lớp học, file lịch học và 2 file .tmp tại thư mục gốc để làm Phần B
### Chuyển file Excel vào data
- Dùng phím tắt Ctrl + X vào file hoc_vien_khoa_3.xlsx
- Di chuyển vào trong file data dùng phím tắt Ctrl + V
### Chuyển file log vào logs
- Dùng phím tắt  Ctrl + X vào file access_log
- Di chuyển vào trong file logs dùng phím tắt Ctrl + V
### Giữ logo, ảnh lớp học, file lịch học và 2 file .tmp tại thư mục gốc để làm Phần B
- Tạo thêm 2 file có đuôi .tmp -> temp_201.tmp , temp_202.tmp
